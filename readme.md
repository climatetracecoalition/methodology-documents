## Climate TRACE Methodology Documents
**Detailed, sector-specific documentation of how Climate TRACE estimates greenhouse gas emissions.**

**Pick your sector** from the [2025 methodology folder](https://github.com/climatetracecoalition/methodology-documents/tree/main/2025) and read its methodology.
   > **Note:** the year folder refers to the release cycle, not the document date or last updated. The current
   > methodologies live in `2025/`; the `2026/` folder holds monthly changelogs for the v5.x releases.
